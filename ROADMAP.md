# Roadmap

AI Project Factory grows through small, verifiable releases. Items are plans rather than commitments;
issue discussion and maintainer capacity determine order.

## 0.1 — Foundation

- [x] Interactive and automation-friendly CLI.
- [x] Next.js, NestJS, and Flutter templates.
- [x] Shared AI-agent context and engineering documentation.
- [x] Automated tests, lint, formatting, build, audit, packaging, and CI.

## Next

- [ ] Add explicit template metadata and compatibility checks.
- [ ] Add optional testing and deployment presets without changing minimal defaults.
- [ ] Run generated-project builds in scheduled CI as framework versions evolve.
- [ ] Add a documented template deprecation and migration policy.
- [ ] Improve accessibility and Windows coverage of interactive prompts.

## Later

- [ ] Add stacks based on demonstrated contributor demand.
- [ ] Support organization-owned template packs with a documented trust model.
- [ ] Provide safe update guidance for previously generated context files.

Suggest or discuss roadmap changes through the feature request template. New stacks should have an
identified maintainer and a plan for testing framework upgrades.
