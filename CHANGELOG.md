## [0.1.0] - 2026-10-07

### Added

- Interactive and non-interactive `init` command.
- Runnable Next.js, NestJS, and Flutter starter templates.
- Shared AI-agent context, architecture, coding, testing, and security documents.
- Atomic project generation with explicit overwrite protection.
- CLI, validation, and all-stack integration tests with coverage.
- Formatting, linting, build, dependency audit, package verification, and GitHub Actions workflows.
- Complete open-source contribution, conduct, security, roadmap, and issue/PR documentation.
